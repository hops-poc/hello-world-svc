# hello-world-svc

hello-world, deliberately thin — the paved-road product demo.

Generated by `paved-road`'s scaffold (`templates/service/`). **The thinness is the point.**
Everything that makes shipping this safe — the gates, the OPA policies, the OIDC roles, the
runtime module, the agents — lives in `paved-road`, not here. A team owning this repo owns
their application code and two thin Terraform callers, nothing else.

Ships through the paved road: PR → gates → dev → human-approved prod.

## How a change ships

1. Branch, push, open a PR. `plan.yml` runs the gate set: lint, typecheck, unit tests,
   gitleaks, Trivy, `tofu validate`/`plan`, and 9 OPA/Conftest policies — plus the
   reporting lane (SBOM, licenses, coverage, Infracost delta) which never blocks.
2. On a gate failure, ReviewBot/Triage explain it as a PR comment, labelled AI-generated,
   and record the action in the agent ledger. They never merge and never approve.
3. Merge to `main` → deploy to dev → smoke test.
4. Prod waits on the `prod` GitHub Environment reviewer. A human approves under their own
   identity; no agent can.

Enforcement is anchored outside the diff — required status checks, a repo ruleset, and
CODEOWNERS are repository settings a PR author cannot edit. A policy file in this repo could
otherwise be deleted by the same PR it would block.

Rollback is a Lambda alias flip to the previous version — seconds, atomic, no Terraform apply.

See `paved-road`'s `DECISIONS.md` for why each gate blocks or reports, and `AI-GOVERNANCE.md`
for what the agents may and may never do.
